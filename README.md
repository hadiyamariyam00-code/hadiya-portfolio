## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/<your-username>/hadiya-portfolio.git
cd hadiya-portfolio
npm install
```

Run locally:

```bash
npm start
```

Build for production:

```bash
npm run build
```

## Environment Variables

This project uses a `.env` file for configuration (not committed to the repo). If you're running it locally, create a `.env` file in the root and add any required keys.
